# 『人生が変わる最強の習慣』レビュー／ギャラリー反映

## 依頼

『人生が変わる最強の習慣』（Testosterone／中野優作）の提供レビュー文と提供画像を、読書withCocoのReviews／Galleryへ反映する。

## 対象ファイルと狙い

- `src/content/reviews/jinsei-ga-kawaru-saikyo-no-shukan.md`: レビュー本文、書誌、問い・見方・一歩、補助購入導線を登録する。
- `src/content/gallery/business-*.md`: 本とココちゃんの画像、読後の余韻、レビューへの関連付けを登録する。
- `public/uploads/gallery/books/*.png`: 提供されたギャラリー画像を、比率を変えずに配置する。
- `public/uploads/review/infographic/*.png`: 提供されたレビュー用画像を、比率を変えずに配置する。

## ブランド上の意図

- Visual thesis: 力強い習慣論の熱量を、ココちゃんが本のそばで受け止め、読者が自分の暮らしへ視線を戻せる一枚の景色として見せる。
- Content plan: 読者の疲れ → 本から受け取った見方の変化 → 体調を土台にする視点 → 今日できる一歩 → 読者への問い、の順でレビューを置く。ギャラリーは画像、短い説明、レビュー導線の順で余韻を補助する。
- Interaction thesis: Reviewsでは本文を主導線にし、関連Galleryへ自然に移動できるようにする。購入リンクは読後の価値提供を読んだ後の補助導線として既存コンポーネントに委ねる。

## 制約

- 本の要約や購入訴求を主役にしない。
- 読者を急かす断定や、習慣による変化の保証を加えない。
- 提供画像の画素・比率を変更しない。既存の未追跡ファイルは変更しない。
