# 確認項目
- レビューの一覧と詳細に掲載され、写真・図解・原稿・購入欄が表示される。
- ギャラリーに作品が載り、写真・キャプション・レビューへのリンクが使える。
- desktop / mobile にレイアウト崩れがなく、lint・typecheck・build・E2E が通る。
- CI と Pages の完了後、本番で両ページと画像を確認する。
- ギャラリーの `generated_at` とメディアマニフェストに追加された2画像の派生ファイルを確認する。ホームに新しいレビューが掲載され、ギャラリー導線も使えることを確認する。
- ギャラリーの紹介文は書誌を繰り返さず、写真に見える景色を伝える。画像の代替テキストと購入リンクに付く既存のアフィリエイト開示を確認する。
