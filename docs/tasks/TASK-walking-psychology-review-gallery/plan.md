# 掲載計画
分類: publish/dev-critical。計画・掲載差分のレビュアー: Claude Review Gate (glm-5.3) / Codex Review。
対象: レビューとギャラリーに各1件、対応する画像2点とメディアマニフェスト、作業記録。
- 見せ方: 木漏れ日の散歩道でココちゃんと一冊を紹介し、レビューでは図解を添える。
- 内容: 本の場面と本人の経験を分け、朝の体にそっと耳を傾けるという問いを残す。本文は依頼者の原稿を掲載する。
- 導線: ギャラリーからレビューへ。購入先は既存の補助欄に置く。
- 上記を既存コンテンツ形式で登録し、desktop / mobile の表示、導線、画像および既定の frontend verify を確認する。レビューと CI 通過後に公開を確認する。
