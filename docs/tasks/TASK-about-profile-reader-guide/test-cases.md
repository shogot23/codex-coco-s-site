# 確認項目

- Aboutから最初の3冊、レビュー検索、公開ワーク、ギャラリーに進める。利用順を強制せず、休む・相談する・終える選択が読める。
- Profileはナビ名と内容が一致し、ココちゃんと書き手を区別する。既存の犬の基本情報を保つ。
- 実作品はpublishedフィルタを経由し、同じ本のReview/Gallery/Workへ進める。下書きは表示しない。
- About/Profileの相互リンク、トップ/ギャラリー/フッターの呼称を統一する。
- About本文に段落を足してもトップの共有紹介が変わらない。Markdownの見出しとリンクをそのまま描画する。
- 1280x720、1440x1080、390x844、360x844で横溢れなし、brand・画像・主CTAが最初の画面に届く。
- 既存の公開サイト全体のlint / typecheck / build / E2Eと配信整合性を通す。
- Claudeの全必須phaseがok:trueであることを確認。CI成功後のPR mergeとPagesの公開HTML・最適化画像を確認する。

- ページ内リンクをクリックして実在する見出しIDへ遷移し、URL hashが一致する。共有frontmatter不在時も固定fallbackを持ち、本文段落順に依存しない。
