# その「もっと」に、自分の望みはどれくらい入っている？
――朝井リョウ『生殖記』を再読して

「もっと成長しなければ」と思うのに、気持ちが追いつかない時があります。

自分には何ができるのか。これからの時代を生きていくために、もっと頑張ったほうがいいのではないか。そんな焦りが募っても、仕事と育児で目の前のことをこなすだけで手一杯。先のことをじっくり考える時間は、なかなか取れません。

そんな日々の通勤中、少し前に読んだ朝井リョウさんの『生殖記』を、オーディオブックで聴き直していました。

初めて読んだ時は、その視点にただただ驚くばかり。二度目は、自分の暮らしに重ねながら、落ち着いて振り返ることができました。

『生殖記』では、私たちが当たり前にしていることが、人間を中心に据えた見方から離れて語られます。仕事をすること、集団の中で暮らすこと。普段は疑わない日常が語られるうちに、私は「成長したい」という自分の望みと、「成長しなければ」という義務感の境目が気になってきました。

家族や会社の一員として過ごすことと、そこで求められる方向へ進みたいと思うことは、いつも重なるのだろうか。自分の目標と、周囲から期待されていることの境目が、曖昧になっていないだろうか。

本に触れている間、忙しさで狭まっていた視野に、少し余裕が生まれました。焦っている自分を、違う角度から眺められるような感覚です。

そこで立ち止まってみました。

自分の焦りは、いったいどこから来ているのだろう。そもそも、なぜ私はもっと頑張ろうとしているのだろう。

何かを成し遂げたい。家族や会社の期待にも応えたい。ただ、それらが一緒になったまま、自分を急かしていたのかもしれません。

生きている時間に、意味や価値を見つけたくなること。私はこの本を通して、その願いにも疑問を持ちました。今日を過ごす自分にも、いつも「何のために」「何につながるのか」と理由を求めていなかっただろうか、と。

再読したからといって、仕事や育児が減ったわけではありません。それでも「もっと頑張らなければ」と感じた時に、その焦りの出どころを一度たずねてみる余地ができました。

**その「もっと」に、あなたの望みはどれくらい入っている？**

もし試してみたくなったら、「もっと頑張らなきゃ」と思った場面を一つだけ思い出してみる。周囲から求められていると感じることと、自分が望んでいることを、一行ずつ書いてみてもよさそうです。これは、読後の問いを暮らしに持ち帰るための小さな試みです。

うまく分けられなくても、すぐに答えを出さなくても大丈夫。書く余裕のない日は、ここで考えるのをやめて休んでもいい。

私もまだ、その境目を考えている途中です。
